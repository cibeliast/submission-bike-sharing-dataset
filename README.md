# Bike Sharing Dashboard

Dashboard ini dibuat menggunakan Streamlit untuk menganalisis data penyewaan sepeda (Bike Sharing Dataset).

## Setup Environment
Pastikan **Python** dan **Pip** sudah terinstal.

1. Buka Terminal (macOS/Linux) atau CMD/PowerShell (Windows).
2. Arahkan direktori ke folder proyek ini.
3. Install semua library yang dibutuhkan:
    ```bash
    pip install -r requirements.txt
    ```

## Run Streamlit App
Setelah instalasi selesai, jalankan perintah berikut untuk membuka dashboard:
```bash
streamlit run dashboard/dashboard.py
```
